## 3. 검증

- `schema.sql`을 PostgreSQL 16에서 실행: **표 45개, RLS 정책 30개 생성**. 제약 5종을 동작 시험했습니다.
  1. 같은 좌우 자리 중복 배치 차단
  2. 3개월 미만 수당 규정 차단
  3. 보너스 포인트 환불 불가
  4. 개인몰 주소 형식 검사
  5. 이체 2인 승인
- 시안 자동 테스트: 판매자 흐름 17개, 개인몰 12개 **모두 통과**, 화면 오류 0건.
