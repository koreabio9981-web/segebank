# 유료회원(회원 패키지) 설계서 (v1.0, 설계만)

> 대표 요구사항 (2026-11):
> 1. 유료회원 금액 **150만 원**, 운영자가 수정·변경 가능
> 2. 유료회원 혜택: **판매원 자격, 수당, 직급, 할인, 상품 모두**
> 3. 무료 회원도 판매원 활동·수당을 받을 수 있는지는 **관리자가 설정**
>
> ⚠ **이 문서는 법률 자문이 아닙니다.** 아래 "위험 높음" 항목은 **변호사 검토 없이 켜지 마세요.**

## 1. 결론

| 항목 | 설계 |
|---|---|
| 유료회원 구조 | **"회원 패키지 상품"**으로 만듭니다. 150만 원을 내면 **그 금액에 맞는 실제 상품**이 배송되고, 등급과 혜택이 붙습니다. 돈만 내는 가입비 형태로 만들지 않습니다 |
| 금액·혜택 변경 | 관리자 화면에서 변경. **수당에 영향을 주는 변경은 3개월 뒤 적용**되도록 시스템이 강제합니다 |
| 무료 회원 판매원 허용 | 관리자 설정(운영 모드 2가지) |
| 기본값 | **모드 1: 판매원 등록은 무료**, 유료회원은 상품·할인·직급 혜택 (위험 낮음) |
| 모드 2 | **유료회원만 판매원·수당** (위험 높음): **변호사 의견서를 시스템에 등록해야만 켤 수 있게** 잠금 |

### 판단 근거

1. 방문판매법은 판매원 **등록이나 자격 유지를 조건으로 일정 수준을 넘는 비용이나 구매 부담을 지우는 것**을 금지 행위로 정하고 있습니다. 허용 한도 금액은 시행령 원문 확인이 필요합니다. 150만 원은 이 한도를 넘을 가능성이 높습니다.
2. 그래서 "150만 원 = 판매원 자격"(모드 2)은 **무등록·불법 다단계로 판단될 위험**이 큽니다. 공정위는 "고액 패키지를 사야 수당을 받는 구조"를 반복해서 제재해 왔습니다.
3. 같은 150만 원 패키지라도 **실제 상품을 주고, 사지 않아도 판매원 활동과 수당을 받을 수 있으면**(모드 1) 일반적인 상품 판매로 볼 여지가 커집니다.
4. 상품 1개 가격 상한(160만 원 또는 200만 원, 확인 필요) 안에 있도록 시스템이 검사합니다. 150만 원은 두 기준 모두에서 상한 아래입니다.

## 2. 혜택별 법적 위험

| 혜택 | 모드 1 (권장) | 모드 2 | 위험 | 설명 |
|---|---|---|---|---|
| 상품 | ✔ 패키지 상품 배송 | ✔ | 낮음 | 판매가에 맞는 실제 상품이어야 함. 반품 가능해야 함 |
| 할인 | ✔ 유료회원 할인율 | ✔ | 낮음 | 일반 쇼핑 혜택 |
| 직급 | ✔ 패키지 PV가 실적으로 쌓여 직급 조건 충족에 반영 | ✔ 구매 즉시 직급 부여 | 모드 1: 중간 / 모드 2: 높음 | "돈 내면 직급"보다 "실적(PV)으로 직급"이 안전 |
| 수당 | ✔ 유료·무료 회원 모두 같은 규정으로 받음 | 유료회원만 받음 | 모드 2: **높음** | 수당 자격을 돈으로 사는 구조 |
| 판매원 자격 | ✔ 누구나 무료 등록 | 유료회원만 판매원 | 모드 2: **높음** | 등록 조건 구매 부담 |

## 3. 운영 모드 (관리자 설정)

```text
[관리자 > 유료회원 설정 > 운영 모드]

(●) 모드 1. 판매원 등록 무료 — 유료회원은 상품·할인·실적 혜택   ← 기본값, 권장
( ) 모드 2. 유료회원만 판매원·수당                              🔒 잠김
     ⚠ 다단계 등록 조건 구매 부담 금지 규정에 위반될 위험이 큽니다.
     잠금 해제 조건:
       1) 변호사 검토 의견서(PDF) 업로드
       2) 대표자 2단계 인증
       3) 적용일 = 오늘 + 3개월 이후 (후원수당 지급기준 변경 통지)
       4) 전체 판매원에게 변경 안내 발송
     → 모든 변경 기록은 감사 기록(audit_logs)에 남습니다.
```

### 3-1. 모드별 동작

| 동작 | 모드 1 | 모드 2 |
|---|---|---|
| 회원가입 | 무료 가입 → 판매원 등록(무료) | 무료 가입(소비자 회원) → 패키지 구매 시 판매원 |
| 개인몰(분양 A) 개설 | 판매원이면 누구나 | 유료회원(판매원)만 |
| 수당 계산 | 판매원 전체 | 유료회원만 |
| 추천 링크 공유 | 판매원 전체 | 유료회원만 |
| 패키지 반품 | 상품 반품 + 패키지 PV·관련 수당 회수 | + 판매원 자격·직급 회수 |

## 4. 회원 패키지 설정 항목 (관리자가 변경 가능)

| 항목 | 예시 값 | 변경 시 적용 |
|---|---|---|
| 패키지 이름 | 소개뱅크 프리미엄 회원 패키지 | 즉시 |
| 판매가 | 1,500,000원 | 즉시(새 구매부터). **가격 상한 검사** |
| 구성 상품 | 상품 A×2, 상품 B×1… (구성 상품 정가 합계 표시) | 즉시(새 구매부터) |
| PV | 1,200 | **수당에 영향 → 3개월 뒤 적용** |
| 유료회원 할인율 | 10% | 즉시 |
| 부여 직급(모드 2) | 실버 | **3개월 뒤 적용** |
| 유효 기간 | 평생 / 1년(갱신) | 새 구매부터. 갱신을 조건으로 하면 "자격 유지 비용"이 되어 위험 높음 |
| 판매 기간 | 상시 / 기간 한정 | 즉시 |
| 1인 구매 한도 | 1회 | 즉시(재고 떠넘기기 방지) |

### 4-1. 변경 규칙 (시스템이 강제)

1. 가격 변경은 **이미 구매한 회원에게 소급하지 않습니다.**
2. **PV, 직급, 수당 자격**처럼 후원수당에 영향을 주는 항목은 적용일이 **오늘부터 3개월 이후**여야 저장됩니다. 저장되면 전체 판매원에게 알림이 나갑니다.
3. 판매가가 **상품 가격 상한**(설정값, 160만 / 200만 원 확인 필요)을 넘으면 저장이 거부됩니다.
4. 구성 상품 정가 합계가 판매가보다 **현저히 낮으면 경고**합니다(상품 없이 돈만 받는 구조로 보일 위험).
5. 모든 변경 전과 후의 값은 감사 기록에 남습니다.

## 5. 반품·청약철회

```text
패키지 구매 → 배송 → (청약철회 기간 내, 기간은 확인 필요) 반품 신청
  → 상품 회수 확인 → 환불
  → 자동 처리: 패키지 PV 차감 → 관련 수당 회수(다음 지급분에서 차감)
             → (모드 2) 판매원 자격·직급 회수, 개인몰 정지
```

- 반품을 어렵게 하거나 위약금을 과다하게 물리면 안 됩니다(확인 필요).
- 판매원의 반품도 보장해야 합니다(재고 떠넘기기 금지).

## 6. 데이터 구조

```sql
-- 회원 패키지 (버전 관리: 변경할 때마다 새 버전)
CREATE TABLE membership_plans (
  id BIGSERIAL PRIMARY KEY, tenant_id BIGINT NOT NULL DEFAULT 1,
  code VARCHAR(20) NOT NULL, version INT NOT NULL,
  name VARCHAR(60) NOT NULL,
  price INT NOT NULL,                    -- 1500000
  pv INT NOT NULL,
  discount_rate NUMERIC(5,2),            -- 유료회원 할인율
  grant_grade VARCHAR(20),               -- 모드 2에서만 사용
  validity VARCHAR(10) DEFAULT 'LIFETIME',
  per_user_limit INT DEFAULT 1,
  product_id BIGINT REFERENCES products(id),  -- 패키지를 상품으로 판매(주문·배송·반품 재사용)
  effective_from TIMESTAMPTZ NOT NULL,
  status VARCHAR(10) DEFAULT 'SCHEDULED',     -- SCHEDULED / ACTIVE / RETIRED
  UNIQUE (tenant_id, code, version)
);
CREATE TABLE membership_plan_items (plan_id BIGINT REFERENCES membership_plans(id), product_id BIGINT, qty INT);

-- 회원별 유료회원 내역
CREATE TABLE memberships (
  id BIGSERIAL PRIMARY KEY, user_id BIGINT REFERENCES users(id),
  plan_id BIGINT REFERENCES membership_plans(id), order_id BIGINT REFERENCES orders(id),
  status VARCHAR(10) NOT NULL,           -- ACTIVE / REFUNDED / EXPIRED
  started_at TIMESTAMPTZ, ended_at TIMESTAMPTZ
);

-- 운영 모드 (변경 이력 포함)
CREATE TABLE distributor_policy (
  id BIGSERIAL PRIMARY KEY, tenant_id BIGINT NOT NULL DEFAULT 1,
  mode SMALLINT NOT NULL DEFAULT 1,      -- 1: 무료 등록 / 2: 유료회원만
  legal_opinion_file TEXT,               -- 모드 2에 필수
  approved_by BIGINT, effective_from TIMESTAMPTZ NOT NULL,
  CHECK (mode = 1 OR legal_opinion_file IS NOT NULL)
);
```

## 8. 수당·35% 한도와의 관계

1. 패키지 매출은 판매원에게 공급한 재화이므로 **35% 기준 금액에 포함**됩니다.
2. 패키지 PV로 생기는 추천 수당 등도 **35% 총액에 포함**됩니다.
3. 패키지 판매가 매출의 대부분을 차지하면 **"상품이 아니라 자격을 파는 구조"**로 보일 위험이 커집니다. 관리자 대시보드에 **"패키지 매출 비중"**을 표시하고, 50%가 넘으면 경고합니다(기준값은 설정 가능).

## 9. 발생할 수 있는 문제와 해결

| 문제 | 해결 |
|---|---|
| 모드 2 운영으로 공정위·수사 대상 | 기본 모드 1. 모드 2는 변호사 의견서 없이는 켤 수 없음 |
| 가격·PV를 바로 바꿔 판매원 불만·법 위반 | PV·직급·수당 관련 변경은 3개월 예약 적용 |
| 반품 거절 분쟁 | 반품 기능 기본 제공, 수당 자동 회수 |
| 돈만 받고 상품이 부실 | 구성 상품 정가 합계 표시, 미달 시 경고 |
| 판매원이 지인에게 패키지 구매를 강요 | 화면에 "구매 선택 사항" 고지, 1인 구매 한도, 신고 기능 |

## 10. 변호사에게 꼭 물어볼 것

1. 판매원 등록·자격 유지 조건으로 받을 수 있는 **비용·구매의 허용 한도 금액**
2. **150만 원 회원 패키지**를 사야 판매원·수당 자격을 주는 구조(모드 2)가 가능한지
3. 패키지 구매로 **직급을 바로 주는 것**이 가능한지
4. 패키지 매출의 35% 기준 금액 포함 방식, 비회원 소비자 매출 포함 여부
5. 패키지 반품 기간과 수당 회수 방법
6. 유효 기간 1년(갱신) 방식이 "자격 유지 비용"에 해당하는지
