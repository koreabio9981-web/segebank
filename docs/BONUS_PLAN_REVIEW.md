## 1. 결론

**제출된 구조는 그대로 시스템에 넣을 수 없습니다.** 법정 한도와 사업 지속성 두 가지 모두에서 문제가 있습니다.

| 점검 항목 | 결과 |
|---|---|
| 후원수당 총액 35% 이하 | ❌ 이미지 기준 **약 45%**, 엑셀 포함 시 **약 115%** |
| 수당이 상품 판매에서만 발생 | ❌ "추천만 해도 수익이 생깁니다"는 **모집 자체에 대한 보상**으로 읽힘 |
| 수익 보장 표현 금지 | ❌ "확실한 보상", "안정적인 수익", "단단한 수익" |
| 판매원 자격에 고액 구매 조건 없음 | ❌ 등급마다 누적 PV 1,500,000(= 150만 원 구매) 요건 |
| 지속 가능한 구조 | ❌ 20등급에 필요한 하위 인원이 **약 210만 명**(2배씩 증가) |

회사가 받은 돈보다 수당으로 더 많이 내주는 구조(115%)는, **새 가입자의 돈으로 앞사람 수당을 주는 돌려막기**가 되어야만 유지됩니다. 그러면 신규 가입이 멈추는 순간 무너집니다. 수사기관과 공정위가 불법 다단계·유사수신으로 판단하는 전형적인 형태입니다.

## 2. 계산 근거 (상품 1건 45만 원 판매 시 지급되는 수당)

| 수당 | 비율 | 금액 |
|---|---|---|
| 쇼핑몰 추천수당 1대 | 10.0% | 45,000원 |
| 마케팅 추천수당 | 10.0% | 45,000원 |
| 롤업 1~20대 각 1% | 20.0% | 90,000원 |
| 단계보너스(1~5대 금액 ÷ 해당 매출로 추정) | 약 5.4% | 약 24,000원 |
| **이미지 기준 합계** | **약 45.4%** | **약 204,000원** |
| 엑셀: 추천인 판매액의 50% | 50.0% | 225,000원 |
| 엑셀: 산하 매출 20% 공유(1/n) | 20.0% | 90,000원 |
| **엑셀 포함 합계** | **약 115.4%** | **약 519,000원** |

- 상품 원가, 배송비, 카드 수수료, 공제조합 비용, 세금을 더하면 회사 손실은 더 커집니다.
- 단계보너스가 6~10대까지 이어지면 비율은 더 올라갑니다.
- 이미지의 $ 표시는 환율에 따라 원화 수당이 바뀌므로 **원화로 정해야** 합니다.

### 2-1. 등급 요건이 사실상 "모집 인원"

| 등급 | 필요한 하위 인원(엑셀) | 누적 |
|---|---|---|
| 5등급 | 32명 | 62명 |
| 10등급 | 1,024명 | 2,046명 |
| 20등급 | 1,048,576명 | 약 210만 명 |

인원 기준 등급은 "몇 명을 데려왔느냐"를 보상하는 것으로 해석될 위험이 큽니다. **판매 실적(PV) 기준**으로 바꿔야 합니다.

## 3. 수정안: 같은 이름과 느낌을 유지하고 30% 안으로

원래 구조의 장점(직추천 보상, 여러 단계 롤업, 직급 공유)은 살리고, 숫자와 기준만 바꿨습니다. **모든 수당은 구매 확정된 상품 매출(PV)에서만** 발생합니다.

| 수당 | 원안 | **수정안** | 비율 |
|---|---|---|---|
| 추천 수당 | 쇼핑몰 10% + 마케팅 10% | **직추천 판매원 구매 PV의 10%**(하나로 통합) | 10% |
| 롤업 수당 | 1~20대 각 1% (20%) | **2~11대 각 1%**, 활동 안 하는 회원은 건너뛰고 위로 올림(롤업 방식 유지) | 10% |
| 직급 공유 수당 | 산하 매출 20%, 1/n | **회사 전체 PV의 7%**를 6등급 이상에게 직급별 지분(30~50)으로 나눔 | 7% |
| 달성 보너스 | 단계보너스 $60~$587.7 | **직급을 처음 달성할 때 1회** 지급, 예산은 회사 전체 PV의 3% 이내 | 3% |
| 추천인 판매액 50% | 1~5등급 | **삭제** | 0% |
| **합계 최대** | 115% | | **30%** (35%까지 5% 여유) |

### 3-1. 직급 기준 수정안 (PV = 구매 확정 상품 실적)

| 등급 | 이름(원안 유지) | 조건(예시, 수정 가능) | 혜택 |
|---|---|---|---|
| 판매원 | — | 판매원 등록(무료) | 추천 수당 |
| 1~2등급 | 일반 | 본인 누적 PV 300 + 직추천 활동 판매원 2명 | + 롤업 2~6대 |
| 3~5등급 | 일반 | 하위 그룹 월 PV 3,000 / 10,000 / 30,000 | + 롤업 7~11대 |
| 6등급 | 가맹점 | 그룹 월 PV 100,000 + 3개 이상 계열에서 각 20% 이상 | 공유 지분 30 |
| 7등급 | 대리점 | 그룹 월 PV 300,000 | 지분 35 |
| 8등급 | 지사 | 그룹 월 PV 1,000,000 | 지분 40 |
| 9등급 | 본부 | 그룹 월 PV 3,000,000 | 지분 45 |
| 10등급 | 총괄본부 | 그룹 월 PV 10,000,000 | 지분 50 |

수정한 점:
1. 등급은 **20개에서 10개로** 줄였습니다. 11~20등급은 현실적으로 도달할 수 없는 숫자라서 홍보에 쓰면 과장 광고가 됩니다.
2. 조건은 **인원이 아니라 매출(PV)**입니다. "직추천 2명"도 **실제로 구매한 활동 판매원**만 셉니다.
3. "계열별 20% 이상" 조건은 한 줄로만 사람을 쌓는 것을 막기 위한 것입니다.
4. **본인 1,500,000 PV(150만 원) 구매 조건은 삭제**했습니다. 등록·자격 조건 구매 강요 위험 때문입니다([유료회원 설계](PAID_MEMBERSHIP_DESIGN.md) 5장).

### 3-2. 수정안 지급 예시 (상품 45만 원, PV 450,000 판매 1건)

| 받는 사람 | 수당 | 금액 |
|---|---|---|
| 직추천인 | 추천 수당 10% | 45,000원 |
| 2~11대 상위 판매원 10명 | 롤업 각 1% | 각 4,500원(총 45,000원) |
| 6등급 이상 전체 | 공유 7% | 31,500원을 지분대로 나눔 |
| 직급 달성자 | 달성 보너스 예산 3% | 13,500원(적립 후 달성 시 지급) |
| **합계** | **30%** | **135,000원** |

## 4. 홍보물 수정 (그대로 쓰면 안 되는 표현)

| 원래 표현 | 문제 | 바꿀 표현 |
|---|---|---|
| 추천만 해도 수익이 생깁니다 | 모집 보상으로 읽힘 | 추천한 분이 **상품을 구매하면** 추천 수당이 지급됩니다 |
| 확실한 보상 / 단단한 수익 / 안정적인 수익 | 수익 보장 | 수당은 판매 실적에 따라 달라지며 **보장되지 않습니다** |
| 단계가 커질수록 수익도 커집니다 + 2배 조직도 | 성공 사례처럼 보이는 가정 | 조직도 그림 삭제, 실제 평균 수당 공개(정보공개 자료) |
| $60, $587.7 | 외화, 확정 금액처럼 보임 | 원화, "최대" 또는 "예시" 표시 |
| 다른 회사명(원원 글로벌) | 상호 혼동 | 소개뱅크 이름으로 새로 제작 |

다단계 홍보물에는 **수당 지급 현황(평균, 분포)**을 함께 보여 주는 것이 안전합니다(정보공개 의무와 연결, 확인 필요).

## 5. 다음 단계

1. 3장 **수정안의 숫자**(비율, 직급 조건, 지분)를 보시고 바꾸고 싶은 부분을 알려 주세요. 파란 글씨처럼 **수정 가능한 값**으로 엑셀 시뮬레이션 표를 만들어 드리겠습니다. 어떤 값을 넣어도 35%를 넘으면 빨간색으로 경고되게 만들겠습니다.
2. 원안(115%)을 꼭 유지해야 하는 이유가 있다면, **변호사 검토를 먼저** 받으세요. 이 구조를 시스템에 구현하는 것은 권하지 않습니다.
3. 홍보 이미지는 4장 기준으로 새로 만드는 것을 추천합니다.
