## ⚠ 이전 설계와 달라진 점: 주민등록번호

- 이전 설계에서는 **"주민등록번호를 받지 않는다"**고 했습니다.
- 그런데 **후원수당을 지급하려면 원천징수와 지급명세서 제출이 필요하고, 이를 위해 소득자의 주민등록번호가 필요합니다.** 소득세법에 따른 법령상 근거가 있습니다. `[법률 확인]`
- 그래서 **수당을 처음 받는 판매원에 한해**, 지급 전 1회 수집하고 **암호화해 보관**하도록 바꿨습니다(개인정보처리방침 3조).
- 일반 회원, 구매자, 판매자에게는 받지 않습니다.
