# 소개뱅크 설계 단계 계획서 (v1.0)

> **이번 단계는 개발하지 않고 설계만 진행합니다.**
> 작성 기준:
> 1. 소개뱅크에 **분양 기능**을 둡니다. 소개뱅크 위에 별도 사이트를 만들어 주는 기능이며, 대상은 3가지입니다.
>    - A. 회원 개인몰
>    - B. 판매자 독립몰
>    - C. 다른 회사에 솔루션 분양
>    자세한 내용은 [분양 기능 설계](MALL_FRANCHISE_DESIGN.md)에 있습니다.
> 2. **모바일 우선 웹**으로 만들고, 휴대폰 홈 화면에 설치되는 앱 형태(PWA)를 지원합니다.
> 3. 앱스토어 등록은 오픈 후 2단계에서 결정합니다.

## 2. 모바일 제공 방식 비교 (추천: ①)

| 방식 | 설명 | 비용·기간 | 앱스토어 | 푸시 알림 | 추천 |
|---|---|---|---|---|---|
| **① 반응형 웹 + PWA** | 웹사이트를 홈 화면에 앱처럼 설치 | 가장 적음 (웹 개발에 포함) | 안 올라감 | 안드로이드 가능, 아이폰은 iOS 16.4 이상에서 홈 화면 설치 시 가능(확인 필요) | **1단계 추천** |
| ② 웹을 감싼 앱(하이브리드) | ①을 앱 껍데기에 넣어 스토어 등록 | 추가 2~4주 + 스토어 비용 | 올라감 | 가능 | 오픈 후 2단계 |
| ③ 전용 앱(네이티브) | 안드로이드·아이폰 따로 개발 | 가장 큼 | 올라감 | 가능 | 지금은 불필요 |

**판단 근거**
1. 쇼핑, 오피스, 판매자 관리는 모두 화면 조회와 입력 위주라 웹으로 충분합니다.
2. 앱스토어는 다단계·추천 보상 앱의 심사가 까다로울 수 있습니다(정책 확인 필요). 웹은 이런 심사 위험이 없습니다.
3. 웹을 먼저 만들어 두면 ②로 넘어갈 때 대부분 그대로 재사용됩니다.

## 4. 지금 결정해야 할 것 (우선순위순)

1. ✅ **판매 방식: 다단계판매로 확정** (2026-11). 등록 준비와 시스템 필수 기능은 [다단계 준비사항](MLM_COMPLIANCE.md)을 참고하세요. 아래 표는 비교용으로 남겨 둡니다. [수당규정서 작성법](BONUS_PLAN_GUIDE.md) 1장을 참고하세요.

   | 판매 방식 | 회원 수당 | 등록·의무 | 후원수당 상한 |
   |---|---|---|---|
   | 일반 쇼핑몰 + 추천 적립금 | 본인 구매 적립·1단계 추천 보상 정도 | 통신판매업 신고 | 해당 없음(설계에 따라 법 검토) |
   | 후원방문판매 | 본인과 바로 아래 판매원 실적에만 수당 | 시·도 등록, 공제조합 가입 등 | **38%**(확인 필요) |
   | 다단계판매 | 여러 단계 실적에 수당 | 시·도 등록, 공제조합 가입, 정보 공개 등 | **35%** |

2. ✅ **도메인: `sogaebank.com`** (사용 중, 메일 수신 확인됨). 분양몰은 그 아래 하위 주소(`kim01.sogaebank.com`)를 씁니다.
2-1. **분양 규칙**: A 개인몰 자동 개설 여부, 개설 자격, 이용료. [분양 설계 14장](MALL_FRANCHISE_DESIGN.md#14-결정해야-할-것-체크리스트)을 참고하세요.
3. **판매자 수수료율과 정산 주기**: 시안은 12%, 월 2회입니다.
4. **회원 가입 조건**: 추천인 필수 여부, 본인인증(휴대폰) 필수 여부
5. **결제 수단**: 카드, 계좌이체, 간편결제(카카오페이, 네이버페이, 토스페이)

## 6. 발생할 수 있는 문제와 해결

| 문제 | 영향 | 해결 |
|---|---|---|
| 판매 방식을 정하지 않은 채 개발 시작 | 수당·등록 구조를 다시 만들어야 함 | 1주차에 판매 방식부터 확정 |
| 수당 총액이 35%를 넘는 설계 | 법 위반, 영업정지 위험 | 수당규정서 작성 시 **시뮬레이션 표**로 검증 |
| 수당 규정을 자주 바꿈 | 변경 적용 **3개월 전 통지** 의무 | 처음부터 보수적으로 설계하고, 화면에 "규정 버전" 관리 |
| 아이폰 푸시 알림 제약 | 알림이 안 갈 수 있음 | 문자·카카오 알림톡을 함께 사용 |
| 참고 사이트와 비슷한 디자인 | 저작권·상표 분쟁 | 새 이름, 로고, 색, 문구 사용(시안 기준 유지) |
