## 1. 먼저 정할 것: 판매 방식

> 📋 제출된 수당 구조(원원 글로벌 이미지·직급 엑셀) 검토와 30% 수정안은 [수당 구조 검토](BONUS_PLAN_REVIEW.md)에 있습니다.
>
> ✅ **소개뱅크는 다단계판매로 확정**되었습니다. 상한 **35%** 기준으로 작성하세요. 등록 서류와 시스템 요구사항은 [다단계 준비사항](MLM_COMPLIANCE.md)에 있습니다.

수당규정서는 판매 방식에 따라 쓸 수 있는 수당 구조가 다릅니다.

| 판매 방식 | 수당을 받을 수 있는 범위 | 후원수당 총액 상한 | 주요 의무 (확인 필요) |
|---|---|---|---|
| **일반 쇼핑몰 + 적립금** | 본인 구매 적립 등 | 해당 없음 | 통신판매업 신고. 추천 보상이 여러 단계로 이어지면 다단계로 볼 수 있어 **법 검토 필요** |
| **후원방문판매** | 본인과 **바로 아래 판매원**의 실적까지만 | **38%** | 시·도 등록, 공제조합 가입 등 |
| **다단계판매** | 여러 단계 하위 판매원의 실적 | **35%** (1년 단위, 판매원에게 공급한 재화 가격 합계 대비) | 시·도 등록, 공제조합 가입, 후원수당 정보 공개 등 |

**판단 기준**: 수당이 2단계 이상 아래 사람의 실적에서 나오면 대부분 다단계판매 규제를 받는다고 보면 됩니다. 정확한 구분은 법률 검토가 필요합니다.

## 2. 작성 원칙 7가지

1. **계산이 가능해야 합니다.** 사람이 아니라 프로그램이 계산합니다. "적절히", "회사가 정하는" 같은 표현은 쓰지 않습니다.
2. **모든 용어를 정의합니다.** PV, 실적 기간, 하위, 직추천, 마감일 같은 말을 먼저 정의합니다.
3. **수당마다 같은 틀로 씁니다.** 이름, 대상, 조건, 계산식, 비율, 한도, 지급일, 예시 순서입니다.
4. **예시를 꼭 넣습니다.** 숫자 예시가 있어야 개발자와 판매원이 똑같이 이해합니다.
5. **한도를 증명합니다.** 모든 수당을 최대로 받는 경우에도 35%(또는 38%)를 넘지 않는다는 계산표를 붙입니다(5장).
6. **반품과 취소 처리를 씁니다.** 이미 준 수당을 어떻게 회수할지 정합니다.
7. **버전과 시행일을 씁니다.** 바꿀 때는 원칙적으로 **적용일 3개월 전 통지**가 필요합니다(시행령 기준, 확인 필요).

## 4. 작성 예시 (가상, 다단계판매 기준)

| 수당 | 대상 | 계산식 | 비율 | 지급 |
|---|---|---|---|---|
| 추천 수당 | 직추천이 있는 판매원 | 직추천 판매원 구매 확정 PV × 비율 | **10%** | 매주 |
| 단계 수당 | 실버 이상 | 2~5단계 아래 판매원 PV × 단계별 비율 | 2단계 5%, 3단계 4%, 4단계 3%, 5단계 2% (**합 14%**) | 매주 |
| 직급 수당 | 골드 이상 | 회사 전체 PV × 3%를 골드 이상 인원에게 똑같이 나눔 | **3%** | 매월 |
| 합계 최대 | | | **27%** | |

**계산 예시**: 이서연(직추천)이 이번 주 PV 1,000을 구매 확정했습니다. 그러면 김민수의 추천 수당은 1,000 × 10% = **100 PV 상당**입니다. 1 PV = [ ]원 환산 규칙이 필요합니다.

## 5. 한도 검증 시뮬레이션 (필수 첨부)

### 5-1. 최대 지급률 계산

모든 판매원이 **모든 수당을 최대로 받는 경우**를 가정해서 더합니다.

| 수당 | 최대 비율 |
|---|---|
| 추천 수당 | 10% |
| 단계 수당 | 14% |
| 직급 수당 | 3% |
| **합계** | **27% ≤ 35% ✔** |

### 5-2. 기준 금액 맞추기

- 35%의 기준은 "판매원에게 공급한 재화 가격 합계"입니다. **부가세 포함 여부 등 산정 기준은 원문 확인이 필요**합니다.
- 수당을 PV로 계산한다면 **PV ÷ 판매가 비율**을 반드시 곱해서 원화 기준으로 다시 검증합니다.
  - 예: PV가 판매가의 80%라면, PV 기준 27%는 판매가 기준 27% × 0.8 = **21.6%**

### 5-3. 연간 시뮬레이션 표 (엑셀로 작성)

| 월 | 공급가 합계 | 추천 수당 | 단계 수당 | 직급 수당 | 수당 합계 | 비율 |
|---|---|---|---|---|---|---|
| 1월 | 100,000,000 | 8,000,000 | 9,000,000 | 2,400,000 | 19,400,000 | 19.4% |
| … | | | | | | |
| **연간** | | | | | | **≤ 35%** |

## 7. 작성 후 확인 체크리스트

- [ ] 판매 방식(일반 / 후원방문 / 다단계)을 정했다
- [ ] 모든 용어를 정의했다
- [ ] 수당마다 계산식과 숫자 예시가 있다
- [ ] 최대 지급률 합계가 35%(또는 38%) 이하다(PV 환산 포함)
- [ ] 반품·취소 시 회수 방법이 있다
- [ ] 의무 구매, 재고 부담, 모집만으로 주는 수당이 없다
- [ ] 수익을 약속하는 표현(예: "월 ○○만 원 보장", "원금 보장")이 없다
- [ ] 코인·가상자산으로 지급하는 조항이 없다
- [ ] 버전, 시행일, 변경 통지 방법이 있다
- [ ] 변호사 검토를 받았다

## 8. 다음 단계

1. **3장 양식의 제1장(용어)과 제2장(직급)**을 채워 보내 주시면 됩니다. 대략적인 내용이어도 됩니다.
2. 받으면 4장처럼 정리하고 **5장 시뮬레이션 표(엑셀)**를 만들어 드리겠습니다.
3. 법률 검토를 받은 뒤 6장 형식으로 바꿔 개발 단계로 넘깁니다.
