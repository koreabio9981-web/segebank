# 소개뱅크 모바일 웹 설계서 (v1.0)

> 독립 사이트, 모바일 우선, PWA(홈 화면 설치) 기준입니다. 개발 전 설계 문서입니다.
> 기능 상세와 DB는 [전체 시스템 설계](SEGEBANK_DESIGN.md)를, 일정은 [계획서](PLAN.md)를 따릅니다.

---

## 1. 사이트 구성과 주소 체계

하나의 도메인 아래에 4개 영역을 둡니다. 로그인 한 번으로 오갈 수 있게 하기 위해서입니다.

| 영역 | 주소 (예: segebank.co.kr) | 대상 | 화면 기준 |
|---|---|---|---|
| 소개뱅크 몰 | `/` | 고객, 회원 | **모바일 우선** |
| 회원 오피스 | `/office` | 회원 | **모바일 우선** |
| 판매자센터 | `/seller` | 판매자 | 모바일·PC 둘 다 (일괄 등록은 PC 권장) |
| 관리자 | `/admin` | 운영자 | PC 우선, 모바일은 조회·승인만 |

### 1-1. 주소 규칙

| 화면 | 주소 | 예 |
|---|---|---|
| 상품 상세 | `/p/{상품번호}` | `/p/101` |
| 카테고리 | `/c/{카테고리}` | `/c/food` |
| 추천 가입 링크 | `/r/{추천코드}` | `/r/kim01` → 가입 화면에 추천인 자동 입력 |
| 상품 공유 + 추천 | `/p/{번호}?ref={추천코드}` | 공유받은 사람이 가입하면 추천인 연결 |
| 판매자 상점 | `/s/{판매자번호}` | `/s/greenfood` |

## 2. 사이트맵

```text
소개뱅크 몰 (/)
├─ 홈
├─ 카테고리 ─ 상품 목록 ─ 상품 상세 ─ (공유 / 찜 / 문의)
├─ 검색
├─ 장바구니 ─ 주문·결제 ─ 주문 완료
├─ 마이 ─ 주문내역(배송조회·구매확정·취소/반품) · 찜 · 최근 본 상품 · 배송지 · 문의 · 설정
├─ 로그인 · 회원가입(추천코드·본인인증) · 아이디/비밀번호 찾기
└─ 고객센터 ─ 공지 · 자주 묻는 질문 · 1:1 문의 · 판매자 입점 안내

회원 오피스 (/office)
├─ 홈 (실적 요약 · 추천 링크/QR 공유)
├─ 실적 ─ 매출내역 · PV
├─ 수당 ─ 수당내역 · 일자별 · 수당규정 보기(버전)
├─ 출금 ─ 출금신청 · 출금내역
├─ 조직 ─ 추천 계보도 · 마이팀
└─ 내 정보 ─ 개인정보 · 비밀번호 · 계좌 · 알림 설정

판매자센터 (/seller)
├─ 입점 신청 · 심사 상태
├─ 홈 (오늘 할 일)
├─ 상품 ─ 목록 · 개별 등록 · 일괄 등록(PC)
├─ 주문 ─ 발주확인 · 송장입력 · 취소/반품
├─ 정산
└─ 문의 · 판매자 정보

관리자 (/admin) ─ 시스템 설계서 3-4장 참고
```

## 3. 모바일 기능

| 번호 | 기능 | 설명 | 단계 |
|---|---|---|---|
| M1 | **홈 화면 설치(PWA)** | "앱처럼 설치" 안내. 아이콘, 시작 화면, 주소창 없는 화면 | 1단계 |
| M2 | **하단 탭 메뉴** | 몰: 홈·카테고리·검색·장바구니·마이. 오피스: 홈·실적·수당·조직·내정보 | 1단계 |
| M3 | **추천 공유** | 추천 링크 복사, QR 코드, 카카오톡 공유, 휴대폰 공유 창 | 1단계 |
| M4 | **알림** | 주문·배송, 수당 지급, 출금 처리, 입점 승인. PWA 푸시 + 카카오 알림톡/문자(대체 수단) | 1단계 |
| M5 | **간편 로그인** | 카카오·네이버 로그인 + 자동 로그인 | 1단계 |
| M6 | **휴대폰 본인인증** | 가입·출금 계좌 등록 시(인증업체 연동) | 1단계 |
| M7 | **간편결제** | 카드 + 카카오페이·네이버페이·토스페이(PG 지원 범위 확인 필요) | 1단계 |
| M8 | **사진 바로 올리기** | 판매자 상품 등록 시 카메라 촬영 → 자동 압축 업로드 | 1단계 |
| M9 | **송장 바코드 촬영** | 판매자가 송장 바코드를 카메라로 읽어 입력 | 2단계 |
| M10 | **생체 인증** | 지문·얼굴로 출금 신청 확인(웹 인증 표준 WebAuthn) | 2단계 |
| M11 | **오프라인 안내** | 인터넷이 끊기면 안내 화면, 최근 본 화면 유지 | 1단계 |
| M12 | **앱스토어 등록** | 하이브리드 앱으로 감싸서 등록 | 2단계 |

## 4. 화면 설계 (모바일 와이어프레임)

> 휴대폰 화면 폭 360~430px 기준입니다. `[ ]`는 버튼이나 입력칸입니다.

### 4-1. 몰 홈 (`/`)

```text
┌──────────────────────────┐
│ 소개뱅크몰        🔔  🛒3 │ ← 위 고정 바
│ [🔍 상품 검색           ] │
├──────────────────────────┤
│ ▣▣▣ 배너 (좌우로 넘김) ▣▣▣ │
│  ● ○ ○                   │
├──────────────────────────┤
│ (식품)(건강)(생활)(뷰티)… │ ← 카테고리 동그라미, 가로 스크롤
├──────────────────────────┤
│ 오늘의 추천        전체 > │
│ ┌────┐ ┌────┐            │
│ │상품│ │상품│  ← 2열 카드 │
│ └────┘ └────┘            │
│ 이름 / 할인% 가격 / PV    │
├──────────────────────────┤
│ 🏠홈  ☰분류  🔍검색  🛒  👤마이 │ ← 하단 탭 고정
└──────────────────────────┘
```

### 4-2. 상품 상세 (`/p/101`)

```text
┌──────────────────────────┐
│ ←                 공유 🛒 │
│ ▣▣▣▣ 상품 사진(넘김) ▣▣▣▣ │
│ 판매자: 그린푸드 >        │
│ 유기농 배추김치 2kg       │
│ 29,000 → 14% 24,900원     │
│ PV 20 · 배송비 3,000원     │
│ (5만 원 이상 무료)         │
├──────────────────────────┤
│ [상세] [후기] [문의] [판매자정보] ← 탭 │
│ …                        │
├──────────────────────────┤
│ ♡  [장바구니]  [바로구매] │ ← 하단 고정
└──────────────────────────┘
옵션이 있으면 [바로구매]를 눌렀을 때 아래에서 옵션 창이 올라옵니다.
```

### 4-3. 주문·결제

```text
배송지 (기본 배송지 자동) [변경]
주문 상품 (판매자별로 묶음) — 판매자마다 배송비 따로 표시
적립금 사용 [ 0 ] [전액]
결제 수단  (카드)(카카오페이)(네이버페이)(토스)(계좌이체)
최종 금액 / 적립 예정 PV
☐ 주문 내용 확인 및 결제 동의 (필수)
[ 26,400원 결제하기 ]  ← 하단 고정
```

### 4-4. 회원 오피스 홈 (`/office`)

```text
┌──────────────────────────┐
│ 김민수님 · 골드      🔔   │
│ ┌──────────────────────┐ │
│ │ 이번 달 수당 211,000원 │ │ ← 큰 카드
│ │ 출금 가능 468,000원    │ │
│ │ [출금 신청]            │ │
│ └──────────────────────┘ │
│ 총매출 │ 누적 PV │ 하위 회원 │ ← 3칸 요약
├──────────────────────────┤
│ 내 추천 링크              │
│ segebank.co.kr/r/kim01   │
│ [복사] [QR] [카카오 공유] │
├──────────────────────────┤
│ 최근 수당 / 최근 주문 / 공지 │
├──────────────────────────┤
│ 🏠홈 📈실적 🎁수당 🌳조직 👤내정보 │
└──────────────────────────┘
```

### 4-5. 추천 계보도 (모바일)

```text
[나 기준 ▼]  [찾기 🔍]   [가로 | 목록]
┌─ 가로 보기: 손가락으로 끌어 이동, 두 손가락으로 확대·축소
│       [김민수]
│     ┌────┼────┐
│  [이서연][박준호][윤지아]
│   …
└─ 목록 보기(휴대폰 기본): 단계별 접기/펼치기
   ▼ 1단계 (3명)
     이서연 · 실버 · PV 1,650   ▶ (2명)
     박준호 · 일반 · PV 540     ▶ (1명)
```

휴대폰에서는 **목록 보기를 기본**으로 하고, 가로 보기는 버튼으로 전환합니다. 화면이 좁기 때문입니다.

### 4-6. 출금 신청

```text
출금 가능 468,000원
신청 금액 [        ] 원   [전액]
수수료 3.3%  - 3,300원
실지급액     96,700원
받는 계좌  국민 ***-7890 [변경]
[ 출금 신청 ] → 지문·비밀번호 확인(2단계) → 완료
```

### 4-7. 판매자센터 모바일

```text
판매자 홈: 오늘 할 일 카드
 [신규 주문 2] [송장 입력 1] [답변 대기 1] [품절 1]
상품 개별 등록: 사진(카메라/앨범) → 이름 → 카테고리 → 가격·재고 → 등록
일괄 등록: 휴대폰에서는 "PC에서 이용해 주세요" 안내 + 양식 메일로 받기
송장 입력: 택배사 선택 → [바코드 촬영](2단계) 또는 직접 입력
```

### 4-8. 회원가입 (추천 링크로 들어온 경우)

```text
1. 약관 동의 (전체 동의 / 필수 3 / 선택 1)
2. 휴대폰 본인인증
3. 아이디·비밀번호
4. 추천인: kim01 (김*수) ✔ 자동 입력, 수정 불가
5. 가입 완료 → 홈 화면 설치 안내
```

## 5. 디자인 기준

| 항목 | 기준 |
|---|---|
| 주 색 | 파랑 `#2457D6` (신뢰) · 강조 주황 `#FF7A1A` (할인, 구매 버튼) |
| 상태 색 | 정상 초록 `#1A8F5A` · 대기 노랑 `#C27A00` · 오류 빨강 `#C23B3B` |
| 글꼴 | Pretendard(무료 글꼴), 본문 15px, 작은 글씨 13px, 제목 20~24px |
| 간격 | 4의 배수(8, 12, 16, 24). 화면 좌우 여백 16px |
| 버튼 | 높이 48px 이상(손가락으로 누르기 쉽게), 주요 버튼은 하단 고정 |
| 카드 | 모서리 12px, 연한 테두리 |
| 다크 모드 | 2단계 |
| 아이콘 | 무료 아이콘 세트(예: Lucide) |

### 5-1. 화면 폭 기준

| 폭 | 대상 | 배치 |
|---|---|---|
| ~599px | 휴대폰 | 1열(상품 2열), 하단 탭 |
| 600~1023px | 태블릿 | 상품 3열 |

## 6. 품질 목표

| 항목 | 목표 | 확인 방법 |
|---|---|---|
| 첫 화면 표시 | 휴대폰 4G에서 2.5초 이내 | Lighthouse(구글 측정 도구) 모바일 점수 80 이상 |
| 이미지 | WebP 자동 변환, 화면 크기에 맞춰 축소 | |
| 접근성 | 글자 대비 4.5:1 이상, 버튼 이름 읽기 | 웹 접근성 지침(WCAG) AA |
| 검색 노출 | 상품 상세는 서버에서 화면을 만들어 전달(SSR), 상품 정보 구조화 | 네이버·구글 검색 등록 |
| 보안 | 전 구간 HTTPS, 출금·계좌 변경 시 재인증 | |

## 7. PWA(홈 화면 설치) 설계

| 항목 | 내용 |
|---|---|
| 설치 정보 파일 | `manifest.json`: 이름 "소개뱅크", 아이콘 192·512px, 시작 주소 `/`, 테마 색 `#2457D6` |
| 오프라인 | 서비스워커(백그라운드 스크립트)로 기본 화면 저장, 끊기면 안내 화면 |
| 설치 안내 | 3번째 방문 시 하단에 "홈 화면에 추가" 안내. 아이폰은 공유 → "홈 화면에 추가" 그림 안내 |
| 푸시 | 알림 허용은 **주문 완료 직후**처럼 필요한 순간에 물어보기(첫 화면에서 묻지 않기) |

```json
{
  "name": "소개뱅크",
  "short_name": "소개뱅크",
  "start_url": "/?source=pwa",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#2457D6",
  "icons": [
    { "src": "/icons/192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icons/512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
```

## 8. 현장 확인 체크리스트 (설계 검토용)

- [ ] 하단 탭 5개 메뉴 이름과 순서
- [ ] 상품 카드에 PV를 보여 줄지(비회원에게도 보여 줄지)
- [ ] 추천 링크 공유 문구(카카오톡 미리보기 제목·이미지)
- [ ] 계보도 기본 보기: 목록 / 가로
- [ ] 알림 종류와 수단(푸시 / 알림톡 / 문자)
- [ ] 판매자 일괄 등록을 휴대폰에서 막을지(PC 권장 안내)
- [ ] 회원가입 시 추천인 필수 여부
- [ ] 로고·대표 색 확정
