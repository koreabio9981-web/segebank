# 외부 연동 목록 (설계 산출물 ⑦, v1.0)

> 소개뱅크가 직접 만들지 않고 **외부 서비스와 계약·연동**해야 하는 항목입니다.
> 업체명은 대표적인 후보이며 **요금·조건·지원 범위는 바뀔 수 있어 계약 전 확인이 필요**합니다.

---

## 1. 결론

1. **꼭 필요한 연동은 14가지**입니다. 그중 **결제(PG), 공제조합, 본인인증, 수당 이체** 4가지가 오픈 일정을 좌우합니다.
2. **가장 먼저 할 일은 PG 상담**입니다. PG사는 **다단계 업종 심사가 까다롭고**, 보통 **다단계판매업 등록증**을 요구합니다. 등록과 PG 심사를 동시에 준비해야 합니다.
3. 대부분 **사업자등록증·통신판매업 신고증·다단계 등록증·통장 사본**이 필요하므로 서류를 한 번에 준비합니다.

## 4. 연동별 설계 메모

### 4-1. PG
- 결제 승인 결과는 **서버에서 다시 확인**합니다(금액 위변조 방지).
- 부분취소를 지원해야 합니다. 한 주문에 여러 판매자 상품이 들어 있기 때문입니다.
- 결제 수단별 수수료는 **주문 상품 단위로 배분**해 판매자 정산과 회사 손익에 반영합니다.
- 다단계 업종이라 심사에서 거절될 수 있으니 **2곳 이상에 동시에 상담**하세요.

### 4-2. 공제조합
- 결제 완료 → 공제번호 요청 → 주문에 저장 → 구매자에게 문자로 안내 → 취소 시 해지 요청
- 실패하면 3회 재시도하고, 계속 실패하면 관리자에게 알립니다. 주문은 "공제 대기" 상태로 둡니다.
- **API 제공 여부와 규격을 가입 상담 때 확인**하세요. API가 없으면 일괄 파일 업로드 방식으로 설계를 바꿉니다.

### 4-3. 수당 이체
- 흐름: 수당 확정 → 지급 파일 생성(계좌, 금액, 원천징수 후) → 관리자 2명 승인 → 이체 → 결과 반영
- 이체 전에 **예금주와 판매원 실명이 일치하는지 확인**합니다.
- 이체 실패(계좌 오류 등)는 다음 회차로 넘기고, 판매원에게 알립니다.

### 4-4. 알림
- **수당 규정 변경 3개월 전 통지**는 법적 의무이므로 발송 결과(성공·실패·시각)를 보관합니다.
- 알림톡이 실패하면 문자로 다시 보냅니다(대체 발송).

## 5. 예상 비용 (참고용, 확인 필요)

| 항목 | 형태 | 비고 |
|---|---|---|
| PG | 결제액의 % 수수료 + 가입비(업체별) | 업종·매출 규모에 따라 협상 |
| 본인확인 | 건당 과금 | 가입 시 1회 |

| 공제조합 | 담보금 + 공제료(거래액 비율) | 조합 문의 |
| 알림톡·문자 | 건당 과금(알림톡이 문자보다 저렴) | |
| AWS(서버·DB·S3·SES) | 월 수십만 원대(초기) | 사용량에 비례 |
