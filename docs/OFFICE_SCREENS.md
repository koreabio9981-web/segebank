# SEGE 오피스 — 화면 목록 (시안 v0.1)

> 이 목록은 원본 사이트(smart79 office)를 직접 보지 못한 상태에서, **일반적인 회원용 업무 화면(백오피스) 구성을 가정**해 만든 것입니다.
> 실제 화면 캡처를 받으면 항목을 추가하거나 빼서 맞춥니다. 이름, 로고, 색상은 원본과 다르게 새로 정했습니다.

시안 파일: `mockup/office/index.html` (브라우저로 열면 바로 보임, 서버 필요 없음)

## 1. 공통

| 번호 | 화면 | 주요 기능 |
|---|---|---|
| C-01 | 로그인 | 아이디/비밀번호, 회원·관리자 구분, 비밀번호 찾기 |
| C-02 | 회원가입 | 추천인 아이디, 기본 정보, 약관 동의 |

## 2. 회원 화면

| 번호 | 화면 | 주요 기능 |
|---|---|---|
| M-01 | 대시보드 | 이번 달 수당, 출금 가능 금액, 하위 회원 수, 최근 공지 |
| M-02 | 내 정보 | 개인정보, 계좌, 비밀번호 변경 |
| M-03 | 조직도 | 내 아래 회원을 단계별로 보기 |
| M-04 | 수당 내역 | 기간별 수당 종류·금액 조회 |
| M-05 | 주문 내역 | 구매 상품, 결제 금액, 배송 상태 |
| M-06 | 출금 신청 | 금액 입력, 신청 내역, 처리 상태 |
| M-07 | 공지사항 | 목록·상세 |
| M-08 | 1:1 문의 | 문의 작성, 답변 확인 |

## 3. 관리자 화면

| 번호 | 화면 | 주요 기능 |
|---|---|---|
| A-01 | 대시보드 | 오늘 가입·매출·출금 요청 건수, 월 매출 추이 |
| A-02 | 회원 관리 | 검색, 등급 변경, 정지/해제 |
| A-03 | 조직도 조회 | 특정 회원 기준 조직 보기 |
| A-04 | 주문 관리 | 주문 상태 변경(결제→배송→완료) |
| A-05 | 수당 정산 | 정산 기간 선택, 계산 실행, 확정 |
| A-06 | 출금 승인 | 신청 목록, 승인/반려 |
| A-07 | 상품 관리 | 상품 등록·수정, 가격, 포인트(PV) |
| A-08 | 공지 관리 | 공지 작성·수정 |
| A-09 | 문의 관리 | 문의 답변 |

## 4. 기본 데이터 구조 (초안)

```text
members    (id, login_id, name, phone, grade, sponsor_id, status, bank, account, created_at)
products   (id, name, price, pv, active)
orders     (id, member_id, total, pv, status, created_at)
bonuses    (id, member_id, period, type, amount, status)
withdrawals(id, member_id, amount, fee, status, requested_at, processed_at)
notices    (id, title, body, created_at)
inquiries  (id, member_id, title, body, answer, status)
```

## 5. 확인이 필요한 것

1. 수당 계산 방식(종류, 비율, 정산 주기). 법적으로 민감할 수 있는 부분이라 실제 규정 확인이 필요합니다.
2. 실제로 쓰는 메뉴: 위 목록에서 빼거나 더할 항목
3. 결제 방식(카드, 계좌이체, 포인트)
