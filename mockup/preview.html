직접 해 보기

판매자 입점부터 판매까지
  1. 판매자센터 왼쪽 위에서 "데모: 신규 사용자"를 고르고 입점 신청
  2. 관리자 › 판매자 입점 승인에서 승인
  3. 판매자센터로 돌아가 상품 일괄 등록 → "예시 파일로 해 보기"(정상 3줄, 오류 4줄)
  4. 몰에서 등록한 상품 확인
주문과 배송
  1. 몰에서 상품 구매
  2. 판매자센터 › 주문에서 발주 확인 → 송장 입력
  3. 마이페이지에서 구매 확정
개인몰 만들기
  1. 개인몰 시안에서 주소에 "admin"을 넣어 금칙어 검사 확인
  2. 소개글에 "수익 보장"을 넣어 차단 확인 → 고쳐서 개설

입력한 내용은 지금 보는 브라우저에만 저장됩니다. 처음 상태로 되돌리려면 각 화면의 [데모 초기화]를 누르세요.
