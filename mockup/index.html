직접 해 보기 ① 판매자 입점 → 관리자 승인 → 상품 등록

1. 판매자센터 왼쪽 위 "데모: 신규 사용자" 선택 → 입점 신청→ 2. 관리자 → 판매자 입점 승인 → 승인→ 3. 판매자센터 새로 고침 → 상품 일괄 등록→ 4. 몰에 상품 노출 확인

직접 해 보기 ② 상품 일괄 등록

판매자센터 → 상품 일괄 등록 → "예시 파일로 해 보기"를 누르면 오류가 섞인 7줄이 검사됩니다. 정상 줄만 등록되고, 오류 줄은 파일로 내려받아 고칠 수 있습니다.
