# 소개뱅크 시안 — 피그마 편집용 파일

시안(mockup/*.html) 63개 화면을 **피그마에서 직접 고칠 수 있는 SVG**로 바꾼 파일입니다.
SVG를 피그마로 끌어다 놓으면 글자는 **텍스트 레이어**, 상자·버튼·표 칸은 **사각형 레이어**로 열립니다.

| 폴더 | 내용 | 용도 |
|---|---|---|
| `svg/` | 화면 63개 (편집 가능한 레이어) | 피그마에 넣어서 수정 |
| `png/` | 같은 화면의 캡처 이미지 | 원본 모습 비교용 |
| `tools/` | 변환 프로그램 (`export.js`, `dom2svg.js`) | 시안을 고친 뒤 다시 만들 때 |

## 피그마에 넣는 방법
1. 피그마에서 파일을 엽니다. 예: 「소개뱅크 시안」 파일에 페이지를 하나 추가하고 이름을 `편집용 화면`으로 바꿉니다.
2. 탐색기(Finder)에서 `svg/` 폴더의 파일을 **한 번에 여러 개 선택해서** 피그마 캔버스로 끌어다 놓습니다.
   - 영역별로 나눠 넣으면 정리하기 쉽습니다: `10_몰_*` → `20_오피스_*` → `30_판매자센터_*` → `40_관리자_*` → `50_개인몰_*` → `60/61_모바일`.
3. 넣은 화면을 모두 선택하고 `Shift + A`(자동 레이아웃)를 누르거나 정렬 도구로 가로로 나란히 놓습니다.
4. 각 화면을 선택하고 `Ctrl/Cmd + Alt + G`(Frame selection)를 눌러 **프레임**으로 바꾸면 프로토타입 연결과 내보내기가 쉬워집니다.
5. 글꼴이 없다는 경고가 나오면 **Noto Sans KR**을 고릅니다(피그마 기본 제공 구글 글꼴).

## 레이어 이름 규칙
- 맨 위 그룹: 화면 이름 (예: `몰 / 주문·결제`)
- 그룹: HTML 클래스 이름 (`card`, `side`, `top`, `tbl`, `node` 등)
- 사각형: `클래스-bg`(배경), `클래스-line`(테두리 한 변)
- 텍스트: 글자 내용 그대로

## 알려진 차이 (원본 캡처와 다른 점)
| 항목 | 피그마에서 보이는 모습 | 고치는 법 |
|---|---|---|
| 그림자 | 없음 | 필요한 카드에 Drop shadow 추가 |
| 이모지(🙂 🛍 등) | 글꼴에 따라 네모(□)로 보일 수 있음 | 이모지를 다시 입력하거나 아이콘으로 교체 |
| 체크박스·라디오 | 단순한 네모·동그라미 | 디자인 시스템 컴포넌트로 교체 |
| 접힌 영역(「양식 작성 규칙 보기」 등) | 접힌 상태만 들어감 | 필요하면 시안에서 펼쳐서 다시 변환 |
| 긴 화면(휴대폰 화면 안 스크롤) | 화면 크기만큼 잘림(클립) | 그룹의 Clip content를 끄면 전체가 보임 |
| 글자 위치 | 1~2px 정도 어긋날 수 있음 | 자동 레이아웃 적용 시 정리됨 |

자동 레이아웃(Auto layout)과 컴포넌트는 적용되어 있지 않습니다. 디자이너가 공통 요소(버튼, 카드, 표, 사이드 메뉴)를 컴포넌트로 묶는 작업이 다음 단계입니다.

## 시안을 고친 뒤 다시 만들기
```bash
# 저장소 최상위에서 실행 (Node.js 18 이상 + Playwright 필요)
mkdir -p /tmp/figma-out
node design/figma/tools/export.js /tmp/figma-out
# 결과: /tmp/figma-out/*.svg, *.png  → design/figma/svg, png 로 복사
```
- 화면 목록은 각 페이지의 왼쪽 메뉴를 자동으로 읽어서 만듭니다. 메뉴를 추가하면 화면도 자동으로 늘어납니다.
- 몰은 장바구니에 상품 2개를 담은 상태로 장바구니·결제·주문 완료 화면을 만듭니다.
- 데스크톱은 가로 1440px, 휴대폰은 390px 기준입니다.
